包租代管（整層租下來再分租）的物件投報率試算網頁。灰哥在 Anne 包租代管課上用。

- 線上網址：https://geniusjohn0502.github.io/rent-roi/
- 正本就是這個資料夾：`~/Documents/04_房地產與投資/Anne包租代管課程/包租投報率試算/`（2026-11-08 灰哥定，放在課程資料夾，不放 `網頁與程式/`）
- 上線前的舊版 `包租投報率試算_灰哥版.html` 已在 2026-11-08 刪除（移到垃圾桶）

## 資料存在哪

- 物件存檔存在**使用的人自己的瀏覽器**裡（localStorage，名稱 `baozu-calc-v2`），不會傳到任何伺服器
- 換電腦或換瀏覽器要用「下載備份檔／從備份檔還原」搬

## 分享代碼（2026-11-08 加入）

- 「產生代碼」把整份試算（成本明細、房間配置、合約參數）壓縮成一串 `BZ-` 開頭的字
- 「複製連結」= 網址＋`#c=代碼`，對方點開就直接帶出試算並跳到「試算結果」
- 「貼上代碼」可以貼代碼，也可以貼整條連結
- 帶出來的試算是一間還沒存檔的物件，對方自己存過的物件不會被動到
- 代碼是按下按鈕那一刻的內容，之後改了數字要重新產生
- 代碼放在網址 `#` 後面，這一段不會傳到 GitHub 的伺服器

## 短代碼（2026-11-08 加入）

- 按「產生代碼」會把長代碼存進 Cloudflare 小倉庫，換成 6 個字的短代碼（例如 `K7Q3MP`），連結變成 `…/rent-roi/#K7Q3MP`
- 小倉庫：Cloudflare Worker `rent-roi-api`（https://rent-roi-api.line-checkin-bot.workers.dev ）＋ D1 資料庫 `rent-roi-db`，程式在 `worker/`
- **60 天沒人存檔就自動清掉**：讀取時離最後一次存檔超過 60 天就當作找不到；每天台灣時間 04:00 排程刪掉過期的（灰哥 11/8 定 60 天；11/14 起從最後一次存檔起算）
- 任何人按「產生代碼」都會存進灰哥的小倉庫（只有物件名稱和數字）
- 小倉庫連不上時，自動退回長代碼，長代碼和舊的 `#c=BZ-…` 連結都還能用
- 改 Worker：`cd worker && npx wrangler deploy`（要先登入 Cloudflare）

## 共用連結：拿到連結的人都能改、存回（2026-11-14 加入）

灰哥 11/14 定：**一條連結大家都能改**（不分修改連結／觀看連結），灰哥、同學、老師都這樣用。

- 從 6 個字的連結打開，上方出現綠色框「你正在看共用連結 XXXXXX」，寫著第幾版、最後修改的人和時間
- **💾 存回這條連結**：存成新的一版，大家重新打開連結就看到。第一次存會問名字（記在自己的瀏覽器 `rent-roi-editor`，可以不填）
- **兩個人同時改**：後存的人會看到「有人比你先存了一版」，可以選「看他的版本」或「用我的蓋過去」（倉庫用版本號擋，不會默默蓋掉）
- **🕘 看舊版本**：每條連結留最近 20 版，「帶到畫面」後再按存回才算真的回到那一版
- **📁 存到我的物件**：先跳說明（共用 vs 只有自己能改），存完畫面換成自己的那份，綠色框消失；之後別人改共用版不會跑進來
- **↻ 看最新版**：重新讀倉庫最新版（不會自動跳，要重新打開或按這個）
- 在共用連結上按「產生代碼」不會產生新連結，直接顯示這條共用連結
- 改到一半關掉，下次打開同一條連結會問「繼續我的修改」還是「看最新版」
- 直接打開網址（沒有 `#代碼`）時，如果上次停在共用連結，會回到那條連結並讀最新版
- 舊的 6 個字連結（11/8–11/14 產生的）也能存回，從第 1 版開始算；更早的長代碼連結 `#c=BZ-…` 只能看
- ⚠️ 拿到連結的人都能改，被改壞只能靠「看舊版本」救回

倉庫的程式：`worker/src/index.js`（`GET/PUT /s/:id`、`GET /s/:id/history`）。表格：`codes` 加了 `updated`、`editor`、`version`，另有 `history` 存舊版本。線上資料庫升級用 `worker/migrations/2026-11-14_共用連結可存回.sql`（11/14 已跑過，不要再跑）。

本機測試：頁面在 `localhost` 打開時會改連本機的倉庫 `http://localhost:8787`（`cd worker && npx wrangler dev --local --port 8787`，第一次先 `npx wrangler d1 execute rent-roi-db --local --file=schema.sql`）。
